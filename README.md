# Лендинг — заказ сайта

Готовый одностраничный сайт (лендинг) для продажи услуг по созданию сайтов. Адаптивный, современный дизайн, с формой заявки.

## 🚀 Демо

Сайт доступен по адресу: `https://hentauchek.github.io/my-landing`

## 📋 Что внутри

Секции сайта:

- **Шапка** — логотип, навигация, кнопка "Заказать"
- **Герой** — заголовок, описание, кнопки действий, анимация счётчиков статистики
- **Преимущества** — 3 карточки (Быстро, Качественно, Доступно)
- **Как это работает** — 3 шага (заявка → работа → результат)
- **Тарифы** — 3 пакета цен (Базовый, Стандарт, Премиум)
- **FAQ** — раскрывающиеся ответы на частые вопросы
- **CTA-блок** — призыв к действию
- **Футер** — ссылки и соцсеть (Telegram)
- **Модальная форма** — форма заявки с полями

## 🛠️ Технологии

- HTML
- CSS (адаптивная вёрстка, CSS-переменные)
- JavaScript (анимации, модальное окно, FAQ-аккордеон, счётчики)

## 📁 Структура файлов

```
├── index.html   — разметка и тексты сайта
├── style.css    — стили и дизайн
└── script.js    — интерактив и анимации
```

## ⚙️ Как запустить локально

Просто открой `index.html` в браузере — ничего больше не нужно.

# 📘 Инструкция для клиентов (как редактировать)

## ✏️ Как поменять тексты

Открой файл `index.html` в любом текстовом редакторе (Блокнот, VS Code).

Заголовки и тексты между тегами — например:

```html
<h1>Заголовок вашего продукта</h1>
```

Просто замени текст на свой и сохрани файл.

## 🎨 Как поменять цвета сайта

Открой файл `style.css`, в самом верху найди блок `:root`:

```css
:root {
    --primary: #2563eb;   /* главный цвет (синий) */
    --primary-dark: #1d4ed8;
    ...
}
```

Замени `#2563eb` на свой цвет (например, зелёный `#16a34a`) и сохрани.

## 💰 Как поменять цены

В файле `index.html` найди секцию с ценами:

```html
<div class="price-card__cost">15 000 ₽</div>
```

Замени число на свою цену.

## 📞 Как поменять контакты

Telegram находится в футере сайта. Замени:

```html
<a href="https://t.me/kullyuki">Telegram: @kullyuki</a>
```

## 🖼️ Как добавить картинку

1. Положи картинку в ту же папку, что и index.html
2. В нужное место добавь:

```html
<img src="название-файла.jpg" alt="Описание">
```

## 📤 Как загрузить изменения на сайт

1. Открой папку с файлами
2. Загрузи изменённые файлы через GitHub, заменив старые
3. Через 1-2 минуты обнови страницу — изменения применятся
